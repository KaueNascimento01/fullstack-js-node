# HTML5 & JavaScript - Estudos Práticos

Repositório de estudos práticos de desenvolvimento web (HTML5, CSS3 e JavaScript ES6+).

##  Portfólio Interativo
Interface SPA desenvolvida para explorar as aulas, visualizar códigos-fonte com realce de sintaxe e testar demonstrações ao vivo.

*   **Online :** (https://github.com/KaueNascimento01/fullstack-js-node.git))
*   **Local:** Clone o repositório e execute `index.html` via Live Server.

---

##  Tecnologias Aplicadas
*   **HTML5:** Estruturação semântica, formulários, tabelas e integração de mídias.
*   **CSS3:** Layouts (Flexbox, Grid), Box Model, Media Queries, Transições, Gradientes e Variáveis.
*   **JavaScript ES6+:** Eventos, manipulação de DOM, condicionais, loops, arrays e recursividade.
